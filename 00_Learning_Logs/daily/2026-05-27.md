## 学习内容

### 路线图核心脉络（快速回顾）

```
AI 工作流 → RAG → Tool Use → MCP → Agent → Memory/Skill → 科研系统
```

**三类核心竞争力：**
1. AI Native 开发能力 — 把 AI 接入日常工程流程
2. Agent 工程能力 — 能设计、实现、评估 Agent 系统
3. 科研增强能力 — 用 Agent 支撑论文阅读、实验、写作

### 关键词定位

| 关键词 | 本质 |
|---|---|
| **Agent** | LLM 从回答器变成任务执行系统 |
| **MCP** | Agent 连接工具/文件/数据库的标准协议 |
| **Skill** | 把经验、流程封装成可复用能力单元 |
| **OpenHands** | 开源 Coding Agent，研究其规划/编辑/执行机制 |
| **HNSW** | 向量检索索引，RAG 性能基础 |
