## 可复用经验

- 架构 Prompt 要先明确目标粒度：系统级 / 模块级 / 接口级 / PoC 级。
- Agent 编排模块不能一开始就做多 Agent，Phase 1 先做单 Agent + Tool Router + SessionStore。
- 对数据库教学演示这类产品，LLM 输出必须被 EXPLAIN / workflow grounding 约束。
- Code Review 不只审代码，也能审文档里的约束冲突和验收口径。

1. 架构 Prompt 和 requirements Prompt 的区别是什么？
   - requirements Prompt 用来澄清「要做什么、验收什么」；architecture Prompt 用来决定「模块怎么拆、接口怎么连、风险怎么控」。
2. 今天 AI 给出的架构方案，有哪些是你不会采纳的？为什么？
   - 暂不采纳复杂 multi-agent、长期 Memory、完整权限系统。这些对 Phase 1 PoC 属于 YAGNI，会拖慢最小可验收路径。
