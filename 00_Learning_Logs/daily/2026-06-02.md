## 遇到的问题

1. 架构文档 Phase 1 8 步原来排 1 周完全不够，3 个月计划需要整体重构
2. `requirements.txt` 中 `mysql-connector-python` 因 SSL 证书问题无法安装
3. README.md 的中文编码导致 Edit 工具匹配失败多次
4. Docker 3307 端口被其他进程占用
5. MySQL 权限问题：`demo@%` 用户无法从容器外部连接（缺少 MYSQL_ROOT_HOST）

## 解决方式

1. 全部路线图重写：6 項目 × 2 周，DB Studio W1-W2 全 8 步
2. `mysql-connector-python` → `pymysql` 替代，驱动安装成功
3. 对编码有问题的文件用 Write 整体重写代替 Edit
4. 将 MySQL 端口从 3307 改为 3308
5. docker-compose 添加 `MYSQL_ROOT_HOST: '%'` 环境变量，重新创建容器后连接正常

## 可复用经验

1. **6 项目 x 2 周才是可行的节奏** - 每个项目有足够时间做完，不做半成品

5. **pymysql 替代 mysql-connector-python**：在 SSL 证书环境有问题的 Windows 上更稳定
6. **MYSQL_ROOT_HOST=% 必须加**：否则 Docker MySQL 的 demo 用户无法从外部容器访问
