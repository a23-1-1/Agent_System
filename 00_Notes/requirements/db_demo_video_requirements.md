## 原始需求

> 给大学数据库课程老师，做一个根据课本知识内容生成具体的演示视频让学生更好的理解知识，将抽象的知识转化为直观可以看见的流程，比如 SQL 语句的执行，有每一步的执行逻辑。

## 已确认决策

| # | 决策 | 含义 |
|---|---|---|
| **Q1** | **双交付物** | 最终交付物 = **MP4 视频** + **课堂可交互网页**（两者都要，非二选一） |
| **Q2** | **自动生成 + 教师可编辑** | 系统提供自动生成流水线；教师可对**每一步的文案与动画**进行编辑后再发布/导出 |
| **Q3** | **AI 讲解词（LLM）** | 需要 **LLM 自动生成讲解/旁白文案**；教师可在生成基础上编辑（与 Q2 一致的人机协作） |
| **Q4** | **MySQL + PostgreSQL** | SQL 演示需对齐 **MySQL 与 PostgreSQL** 的真实执行计划语义（非仅通用抽象模型）；教学场景允许简化，但须明确标注 |
| **Q5** | **全课程章节覆盖** | 覆盖**数据库课程全部知识章节**（完整课纲范围），不仅限于 SQL 子集；含 ER 图、范式、事务/锁、索引与 B+ 树、存储与恢复等 |
| **Q6** | **三场景并重** | **教师备课**、**课堂现场教学**、**学生课后自学** 均需支持，UX 与分享方式按场景分别优化 |
| **Q7** | **无硬截止 + 预算充足** | **无固定上线截止日期**；预算充足；**允许调用付费 API**（LLM、TTS、云渲染等，需可审计用量） |
| **Q8** | **LMS 集成** | 需要对接学校 **LMS**（如 Moodle、超星/Chaoxing 等）：嵌入演示、链接分享、与课程/作业上下文关联（具体协议待架构选型） |
| **Q9** | **真实教学产品** | 定位为**真实教学产品**（可长期课堂使用），非课程大作业/毕业设计级别的范围收缩 |
| **Q10** | **字幕 + 双语** | 视频/演示需要 **字幕**；支持 **双语**（至少中英，语言对可配置） |

**产品形态归纳：** 面向大学数据库课教师的**全课纲内容生产 + 三场景教学**工具——从课本各章节知识点与 SQL 示例出发，经 **LLM 自动生成分步讲解与可视化初稿**，教师精修每步文案与动画后，产出**课堂可交互网页**与**带字幕的双语 MP4**；执行语义以 MySQL/PostgreSQL 为参照；支持 **LMS 嵌入**与**学生课后自学**；按可上线教学产品标准验收，可采用付费 API 构建生产级流水线。

## 1. 产品方向（已收敛）

在全部 Q1–Q10 确认后，产品收敛为 **方向 C+（全课纲 · 三场景 · 双交付）**：

| 能力 | 说明 |
|---|---|
| 教师工具 | 备课、编辑、发布演示；案例库与版本复用 |
| 分步交互 | 课堂逐步播放/暂停/前进/后退；学生课后同演示只读/跟练 |
| 双出口 | 同一演示源导出 **交互网页** + **带字幕 MP4**（双语音轨或字幕轨） |
| 人机协作 | LLM 自动生成讲解词与初稿 → 教师编辑每步文案/动画 → 定稿 |
| 全课纲 | SQL 执行 + ER/范式/事务/索引/存储等非 SQL 章节模板 |

方向 A（纯自动视频、无编辑）与方向 B（纯交互、无视频）均**不满足**当前交付要求，仅可作为子能力存在于流水线中。

## 2. 需求摘要

为大学数据库课程教师提供**基于课本全课纲知识点生成可视化演示内容**的生产工具，将 SQL 执行、ER 建模、范式、事务与并发、索引结构等抽象概念转化为**可逐步展示的执行/推理流程**，并同时支持 **教师备课**、**课堂现场分步演示**、**学生课后自学** 三种使用场景。

系统提供 **LLM 驱动的自动生成流水线**（讲解词、分步说明、动画初稿）；教师可**编辑每一步的说明文案与动画表现**，再发布/导出。SQL 相关演示的执行计划与步骤语义应对齐 **MySQL 与 PostgreSQL**（可切换或并排对比），并在与真实引擎不一致处标注**教学简化**。

**交付物：** 课堂可交互网页 + 可分发 **MP4**（含**字幕**，支持**中英双语**）。**集成：** 支持嵌入学校 **LMS**（Moodle、超星等）。**资源：** 无固定上线截止日期，预算充足，**允许付费 API**（LLM、TTS、云服务等），整体按**真实教学产品**的质量、稳定性、合规与可维护性要求设计与验收。

## 3. 用户故事

### 教师 — 备课

- **As a** 大学数据库课程教师  
- **I want** 按课本章节选择知识点模板，输入 SQL/概念要点后由系统 **LLM 生成分步讲解与可视化初稿**，并编辑任一步文案与动画  
- **So that** 我在开课前完成可复用的演示包，并同步准备课堂网页与课后 MP4

### 教师 — 课堂

- **As a** 大学数据库课程教师  
- **I want** 在课堂用交互网页 **逐步播放/暂停/前进/后退**，必要时切换 MySQL/PostgreSQL 计划对照  
- **So that** 学生能跟随节奏理解抽象流程，而非仅观看成品视频

### 学生 — 课后自学

- **As a** 数据库课程学生  
- **I want** 通过 LMS 或分享链接访问**同一演示**的只读交互页或 **带字幕的双语 MP4**  
- **So that** 我能按自己的节奏复习全课纲各章内容，并把课本理论与引擎级执行过程对应起来

## 5. 边界条件与异常场景

| 场景 | 期望行为 |
|---|---|
| 输入 SQL 语法错误 | 提示错误位置；可演示「解析失败」或修正建议 |
| 知识点过于宽泛 | 引导按**课纲章节**拆分子主题或选择模板 |
| 复杂 SQL / 复杂概念图 | 分步展示核心步骤；过深细节可折叠并标注「简化演示」 |
| MySQL 与 PostgreSQL 计划不一致 | 并排或分 tab 展示差异，并文字说明原因 |
| 课本内容与 SQL/概念输入不匹配 | 警告并允许教师手动绑定章节节点 |
| **LLM 生成讲解词不准确** | 教师可逐步编辑；保留「AI 初稿」与「教师定稿」版本对比（可选） |
| **LLM/TTS 付费 API 失败或限流** | 降级：保留已生成步骤与网页；提示重试；支持仅用教师手写文案发布 |
| 导出 MP4 失败或超时 | **交互网页仍可用**；提示重试或降低分辨率/帧率 |
| 无网络 / 离线课堂 | 支持本地运行或预下载演示包（含网页 + 可选 MP4 + 字幕文件） |
| 演示与真实引擎行为不一致 | **必须**标注「教学简化模型」 |
| 教师未编辑直接发布 | 允许，但 UI 提示「建议校对 AI 生成讲解与动画」 |
| **LMS 嵌入失败**（域名/CSP/未授权） | 提供独立分享链接与 SCORM/xAPI 等备选（待架构定一种主方案） |
| **双语/字幕不同步** | 导出前校验时间轴；MP4 至少提供默认语言字幕 + 可选第二语言字幕轨 |
| **学生自学越权编辑** | 学生模式只读；无教师权限不可改演示源 |
| 课纲章节暂无模板 | 提供通用「概念分步」模板 + 教师自定义步骤 |

## 6. 验收标准（可测试）

- [ ] 教师选择**课纲章节节点**并输入合法 `SELECT ... JOIN ...` 后，**60 秒内**（含 LLM 调用）生成分步演示初稿（至少 3 步：解析 → 计划 → 结果），且每步含 **AI 生成讲解文案**
- [ ] 教师可 **修改任一步讲解词与动画** 并保存；修改后网页与 MP4 导出内容一致
- [ ] 同一演示可 **发布为课堂可交互网页**（浏览器可逐步操作）
- [ ] 同一演示可 **导出可播放 MP4**，步骤与网页一致；MP4 含 **至少一种语言字幕**，并支持 **中英双语**（双字幕轨或双语字幕文件）
- [ ] **全课纲**模板覆盖验收：至少覆盖 **8 大类**章节（示例：单表/JOIN SQL、ER 建模、范式、事务与 ACID、锁/并发、索引与 B+ 树、查询优化与执行计划、存储/日志恢复示意），每类至少 1 个可生成演示
- [ ] 对同一 SQL，能展示 **MySQL 与 PostgreSQL** 的执行计划或步骤差异（或明确标注仅支持其一时的原因）
- [ ] 所有与引擎不一致处有 **「教学简化」** 可见标识
- [ ] 语法错误 SQL 不崩溃，有明确错误提示
- [ ] **三场景**验收：① 备课：保存草稿与版本；② 课堂：逐步控制无卡顿；③ 学生：只读链接可自学，不可改源演示
- [ ] **LMS**：至少在 **1 种**目标 LMS（Moodle 或 超星二选一）上完成 **嵌入或课程内链接** 试通（教师发布 → 学生从课程页打开）
- [ ] **1 名真实教师用户** 在 **10 分钟内** 完成「选章节 → 生成（含 AI 讲解）→ 编辑一步 → 发布网页 → 导出带字幕 MP4 → LMS 试嵌入」全流程
- [ ] **付费 API**：在测试环境记录 LLM/TTS 调用次数与失败降级路径；**默认不**将含敏感 SQL 的原文发往未授权第三方（见技术约束）
- [ ] 系统满足**真实教学产品**基线：演示可保存复用、关键路径无阻塞性缺陷、双语字幕与导出可重复

## 7. 不在范围内（明确排除项）

以下**不在**本期产品范围（窄排除，避免与已确认决策冲突）：

- 完整**自建**数据库管理系统或生产级查询执行引擎（以解释/可视化既有引擎与教学模型为主）
- **自动批改**学生作业、**在线考试命题与防作弊**系统（除非后续单独立项）
- 覆盖数据库**内核全部实现细节**（如完整 Buffer Pool 页级仿真、生产 WAL 回放），除非单独立项
- **仅**通用抽象 SQL、**不**区分 MySQL/PostgreSQL 的执行计划演示
- **仅** MP4 或 **仅** 交互网页的单交付形态
- **仅** 全自动、教师**不可编辑**步骤与讲解词的流水线
- 按**课程大作业**质量交付、无运维与复用要求
- 从整本 PDF 课本**零人工介入**批量生成**全书**高质量视频（允许章节级生成 + 教师校对）
- **商业级非线性剪辑台**（多轨特效、复杂转场、影视后期工作流）
- **替代 LMS** 本身的课程管理、选课、缴费、全校数据中台
- **所有** 全球语言对（本期双语以**中英**为主，其他语言对可作为后续扩展）

| 部署 | Web 为主；支持离线包；可选校内私有化 |
| 数据隐私 | 学校合规；敏感 SQL/数据默认不出境；付费 API 需说明数据留存策略 |
| 成本 | 无硬截止前提下控制单次生成成本可观测（教师可见预估或配额） |
| 质量基线 | 关键路径稳定、演示版本化、三场景与 LMS 试通 |
