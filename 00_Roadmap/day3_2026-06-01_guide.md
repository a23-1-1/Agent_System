### 背景

根据 [`architecture.md`](../02_DB_Demo_Studio/docs/architecture.md) Phase 1 实施步骤：

| 顺序 | 交付物 | 验收 |

| **2** | `db-engine` + `execution-workflow`（SQL 路径） | EXPLAIN → 步骤 DAG |

**今天的目标是 PoC #1 的第一步：定义 DemoPackage JSON Schema + 手写一个真实样例。**

**产出：** `02_DB_Demo_Studio/logs/2026-06-01_poc1_requirements.md`

### Step 2 — 编码：demo-schema 模块（30 min）

创建以下文件：

**文件 1：`02_DB_Demo_Studio/packages/demo-schema/schema.json`**

DemoPackage JSON Schema（参考 architecture.md 接口定义）：
- `DemoPackage`：id、title（zh/en）、steps[]、metadata 等
- `DemoStep`：id、order、workflowPhase、narration（zh/en）、visuals、groundingRef
- 含 `workflowTrace` 可追溯 AI 生成链
- 含 playback 字段（默认步进时长、字幕）

**文件 2：`02_DB_Demo_Studio/packages/demo-schema/examples/join-query.json`**

一个**手写**的 JOIN 演示样例 JSON（5 步）：
```
Step 1: lex — SELECT ... FROM A JOIN B ON ...
Step 2: parse — 语法树解析
Step 3: plan — EXPLAIN 执行计划
Step 4: execute — 执行过程
Step 5: result — 结果集
```

**为什么用 JOIN 做第一个样例：**
- 覆盖 5 个 workflowPhase（lex → parse → plan → execute → result）
- 最典型的数据库教学场景
- 架构文档中有明确 grounding 要求
