    *   **问题描述**: `DIFF_MAX_CHARS = 8000` 硬编码限制了 Git Diff 的字符数。这存在严重的逻辑缺陷和潜在的静默失败问题。如果代码变更量较大，实际 diff 超过 8000 字符，脚本将截断 diff 发送给 LLM，导致审查结果不完整。更严重的是，截断可能发生在文件的中途，导致 LLM 看到不完整的、语法上或逻辑上不成立的代码片段，从而产生误报或漏掉真正的 Bug。代码中没有对此截断行为进行任何日志或警告。

