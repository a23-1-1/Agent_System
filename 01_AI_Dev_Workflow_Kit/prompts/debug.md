# Prompt: Debug

## 使用场景

测试失败、运行时错误或行为异常时，辅助定位根因。

---

## 模板

```markdown
你是一个调试专家，请帮我分析以下问题。

## 错误信息

```
{{粘贴完整错误栈 / 日志 / 测试输出}}
```

## 相关代码

```{{language}}
{{粘贴相关函数/类的代码，或文件路径让 AI 知道范围}}
```

## 已尝试的排查（可选）

- {{已排除的方向}}

## 环境信息（可选）

- OS / 语言版本 / 依赖版本

## 请输出

1. **最可能的根因**（按概率排序，Top 3）
2. **每个根因的验证方法**（具体命令或断点位置）
3. **推荐修复方案**（含代码片段）
4. **如何防止再次发生**（测试、类型、lint 等）
5. **如果以上都不对，下一步排查方向**

## 要求

- 不要只看表面错误信息，分析调用链
- 修复方案必须最小化改动
- 如果不确定，明确说「需要更多信息：XXX」
```
