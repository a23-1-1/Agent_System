# Prompt: 重构

## 使用场景

技术债清理、模块拆分、命名统一、提取公共逻辑。

---

## 模板

```markdown
你是一个重构专家，请帮我制定安全的重构计划。

## 重构目标

{{描述想要达到的状态，如「提取 UserService」「统一错误处理」}}

## 涉及范围

- 文件/目录：{{列表}}
- 不影响：{{明确不动的部分}}

## 现有代码示例

```{{language}}
{{关键代码片段}}
```

## 约束

- 必须保持现有测试通过
- 偏好小步提交（每步可独立 revert）
- {{其他约束}}

## 请输出

1. **重构前后对比**（结构变化说明）
2. **分步计划**（每步：改动内容 → 验证方式 → 预计风险）
3. **需要新增/修改的测试**
4. **回滚策略**
5. **不建议做的过度重构**（YAGNI）

## 要求

- 每步改动范围小，可独立验证
- 不改变外部行为（除非目标明确要求）
- 标注 breaking change（如有）
```
