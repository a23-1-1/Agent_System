## 我自己原本会怎么做

从头写一个 React 组件，先搭 Vite 脚手架、装依赖、写 TSX，至少 2 小时才能跑起来。

## AI 帮我做了什么

1. **架构设计**：直接生成一个自包含的 `player.html`（288 行），零依赖，浏览器双击就能跑
2. **UI**：标题区、进度条（带点击跳转）、phase 标签、讲解词区、播放控制栏、键盘快捷键提示
3. **播放控制**：←/→ 逐步切换、空格键自动播放（5s/步）、暂停、进度条点击跳转
4. **数据**：内嵌 DemoPackage JSON（6 步，完整中英文讲解），可直接替换为外部 JSON

## 哪些地方有效

- **零依赖范式**：单个 HTML 文件 + 内嵌 JSON，双击即运行，PoC 阶段调试效率极高
- **键盘快捷键**：← → Space 完全对齐架构文档中的验收标准
- **进度条可点击**：教师可以直接跳到想看的某一步，不用逐步翻
- **phase 变换可视化**：上方进度条显示所有步骤，label 实时更新当前 workflowPhase

## 哪些地方无效

- 内嵌 JSON 的方式只适合 PoC 阶段。Player 未来需要从外部加载 DemoPackage（`fetch('demos/xxx.json')`）
- 没有 visuals 渲染（高亮 SQL、plan tree 动画），当前只显示讲解词文本
- 自动播放只是固定 5s/步，没有根据 narration 长度自适应

## 我如何修正 AI 输出

- 中英文双语保留，但 HTML 只展示中文（英文做 data 属性保留，未来加 toggle 按钮）
- 调整了 controls 布局：播放按钮更突出（蓝色圆形），放置顺序为 prev → play → next

## 可复用经验

1. PoC 阶段「单 HTML 文件」模式值得保留到 Day 5-6，验证通过后再迁移到框架
2. 键盘快捷键的验收标准（←→Space）应该在 Player 开发前就写好，避免边写边想
3. 进度条设计和 phase 标签可以直接复用到正式版 Player
